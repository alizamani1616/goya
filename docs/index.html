گویا یه زبان برنامه‌نویسی واقعیِ فارسیه: کلیدواژه‌ها فارسی، اعداد فارسی چاپ می‌شن، پیام خطاها فارسیه، و تقویم شمسی از روز اول داخل خود زبانه. بدون آکولاد و سمی‌کالن — بلوک‌ها با تورفتگی، تا تایپ فارسی راحت بمونه. مفسرش با پایتون خالص نوشته شده؛ یعنی کل اکوسیستم پایتون پشتشه.

⬇ نصب و اجرا

سه خط، همین

# ۱) پروژه رو بگیر
git clone https://github.com/alizamani1616/goya
cd goya

# ۲) یه برنامه اجرا کن
python -m goya run examples/salam.goya

# ۳) یا محیط گرافیکی رو باز کن (همین «تست سریع»!)
python -m goya ide
🖥 دستور goya ide محیط کامل رو باز می‌کنه: ویرایشگر راست‌چین با رنگ‌آمیزی، قالب‌های آماده (تایپ کن «اگر» تا ببینی!)، دکمه اجرا و پنل ورودی — همه محلی، بدون اینترنت.
📦 نسخه‌ی pip و فایل اجرایی goya.exe توی نقشه‌راهه.
