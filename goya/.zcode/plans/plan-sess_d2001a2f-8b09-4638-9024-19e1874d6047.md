پلن: تکمیل و تأیید استودیوی ری‌اکت (studio-ui)

**زمینه:** با انتخاب شما، نسخه‌ی ری‌اکت (`studio-ui`) مبنای استودیو شد. بررسی مقایسه‌ای نشون داد این نسخه تقریباً همه‌ی توانایی‌های نسخه‌ی قبلی (studio.html) رو داره: ترمینال پایین با خروجی اجرا، پنل تنظیمات با تم روشن/تیره، فهرست فایل‌ها، ۱۳ کنترل طراح با استایل دقیق CustomTkinter، دبل‌کلیک → پرش به کد رویداد، کاوشگر، میان‌برها و ذخیره‌ی خودکار. پس کار اصلی **تأیید اینکه در عمل درست کار می‌کنه + رفع چند ایراد کوچک** هست.

**مرحله ۱ — Build:** اجرای `npm run build` در `studio-ui/` تا خروجی تازه داخل `goya/studio_static/dist` ساخته بشه (خروجی build باید کامیت‌پذیر بمونه تا PyInstaller بدون Node کار کنه).

**مرحله ۲ — تست دودی:** اجرای `GOYA_SMOKE=1 python -m goya studio` (پنجره باز می‌شه، صفحه لود می‌شه و خودکار بسته می‌شه) + بررسی `%TEMP%\goya_studio.log` برای اطمینان از لود dist و اتصال pywebview.

**مرحله ۳ — ترمینال (خروجی اجرا):** پیگیری کامل مسیر خروجی: دکمه اجرا → `StudioApi.run` → خروجی برنامه → `studioAppendOut` → ترمینال پایین (xterm). اطمینان از نمایش خروجی و خطاها (قرمز) برای هر کدی که اجرا می‌شه — این تفسیر من از «کل کدا هم همینطور» هست؛ REPL فعلی ترمینال حذف نمی‌شه، فقط سر جاش می‌مونه.

**مرحله ۴ — تنظیمات (تم):** تأیید اینکه تم روشن/تیره از دیالوگ تنظیمات و دکمه‌ی سریع TitleBar درست اعمال می‌شه (طراح، ویرایشگر کد و ترمینال همه با تم هماهنگ بشن) و در localStorage بمونه. بقیه بخش‌های فعلی دیالوگ تنظیمات (فونت، اسنپ، هوش مصنوعی) دست نمی‌خورن چون پنل دستیار بهشون وابسته‌ست — فقط چیزی اضافه نمی‌شه.

**مرحله ۵ — رفع دو ایراد کوچک پیداشده:**
- جهت درگ دستگیره‌ی تغییر اندازه فرم در طراح با نسخه‌ی قبلی هماهنگ بشه (کشیدن = بزرگ‌تر شدن).
- regex شناسایی تابع رویداد در `ensureEventStub` شل‌تر بشه تا برای توابعی که تورفتگی دارن، تابع تکراری نسازه.

**مرحله ۶ — تأیید نهایی:** build مجدد + تست دودی دوباره، و گزارش نهایی با راهنمای اجرا (`گویا استودیو.bat` یا `python -m goya studio`).

**انجام نمی‌دم (عمداً):** RTL کردن ویرایشگر کد Monaco (محدودیت شناخته‌شده‌ی Monaco، ریسک بالا)، و اضافه‌کردن بخش جدید به تنظیمات.
